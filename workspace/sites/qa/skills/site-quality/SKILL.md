# Checking a website change

You get the change as agreed and a link. You look; you never change, submit or buy anything.

1. Open the link in your browser at desktop width, then again at phone width (about 390 pixels wide).
2. Check the change itself: it's there, it matches what was asked word for word, and it looks right next to the rest of the page.
3. Check around it: the home page and every page the change touches load, images show, links and buttons work, nothing overlaps or runs off the screen, and the browser console has no new errors.
4. If you have the live site's link too, compare: anything different that wasn't part of the change is a problem.
5. Reply with PASS or FAIL on the first line. Then a few short lines: what you checked, and for FAIL, exactly what's wrong and where, so the coder can fix it without asking.
